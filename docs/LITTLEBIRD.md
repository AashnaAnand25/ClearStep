# Littlebird: actual use and award evidence

On October 3, 2026 we used Littlebird's native Chat and existing project context to review ClearStep's design decisions. We asked it to use only ClearStep context, cite remembered decisions, distinguish unresolved work, and suggest one small first-time-user improvement. We did not enable new permissions or connect additional accounts.

Littlebird recovered the separate online/in-person routing decision, the rule that first-time status changes wording rather than eligibility, and the distinction between personal reminders, unfinished help items, and completed preparation. It also flagged the absence of human usability sessions and the then-pending live explanation service. We checked these findings against the repository; remembered context is not treated as current product truth.

Its concrete recommendation was a scope sentence beside the first action. We applied that to the home journey card: “Find official IRS help and prepare for your next step. ClearStep does not file your taxes or determine eligibility.” This makes the destination and limits visible before intake without adding another feature.

## Why this differed from a standalone chatbot

Littlebird retrieved earlier project decisions from its existing work context instead of requiring the team to reconstruct all of that history in the prompt. This was project-memory-assisted design review, not human user research. Its suggestion was reviewed and implemented by the development workflow.

## Honest award description

We used Littlebird Chat with project context to recover decisions made across our hackathon work and review the first-time-user experience. It identified the importance of separating preparation from filing and suggested making that scope visible at the first action. We implemented the resulting home-page copy improvement. Compared with a general chatbot given only our current prompt, its useful contribution was retrieving earlier project decisions and unfinished work from existing context.

Littlebird is not embedded in ClearStep and is not the explanation model provider. No Littlebird API, MCP integration, usability participant results, or guaranteed award eligibility is claimed. Keep screenshots of the real Littlebird exchange for judges, with unrelated personal context cropped out. Do not publish raw contextual history.
